# Mana Corner - Cafe Management System

## Features

### 1. **Billing Module** 🧾
- Menu items selection with pricing
- GST calculation (Indian standards: 5%, 12%, 18%, 28%)
- Dynamic bill generation
- Print-ready invoices
- Item quantity management

### 2. **Expense Tracking** 💸
- Date-wise expense logging
- Bill/receipt upload (screenshot support)
- Category-based expense grouping
- Monthly/yearly summaries

### 3. **Financial Analytics** 📊
- Profit & Loss calculations
- Revenue vs Expenses dashboard
- Trend analysis

### 4. **AI-Powered Insights** 🤖
- Predictive spending forecasting
- Cost-cutting recommendations
- Business intelligence advisor
- Budget optimization suggestions

### 5. **Profit Sharing** 💰
- Multi-owner profit distribution
- Configurable sharing percentages
- Settlement tracking

### 6. **Budget Forecasting** 🎯
- Running cost projections
- Future expense predictions
- Cash flow planning

## User Roles

- **Owner Accounts (3)**: Full access to all features
- **Guest Accounts (2)**: Billing operations only

## Tech Stack

- **Frontend**: React 18, Redux, Material-UI, Chart.js
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: JWT
- **File Upload**: Multer
